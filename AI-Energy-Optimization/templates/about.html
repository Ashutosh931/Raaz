Project Abstract & Objectives
Final Year Project 2026
AI-Based Smart Energy Consumption Prediction and Optimization System

Unmonitored electricity usage and inefficient appliance scheduling contribute significantly to high utility bills and peak electrical grid strain. This project presents an intelligent full-stack system that leverages Machine Learning (Random Forest Regression) to accurately predict future residential energy consumption, identify peak-demand hours, calculate electrical bills with tiered domestic tariffs, and dynamically deliver personalized, context-aware energy conservation recommendations.

Core Objectives:
  • Accurate Consumption Forecasting: Predict hourly and daily electricity usage based on weather, occupancy, time of day, and historical lag features with over 95% \(R^2\) precision.
  • Peak Load Identification: Automatically detect high-demand evening windows (18:00–22:00) to incentivize load shifting away from grid stress periods.
  • Explainable AI Intelligence: Quantify feature contributions (temperature, previous consumption, appliances) to explain model decisions transparently during college viva examinations.
  • Actionable Optimization & Simulation: Provide a dynamic recommendation engine and interactive saving simulator for tangible monetary and carbon reductions.
System Architecture Flow:
User Input / Smart Meter CSV → Flask Web Interface → Data Cleansing & Lag Extraction → Random Forest ML Regressor → SQLite Database → Live Dashboard & Savings

Viva Quick Checklist
1. Why not Deep Learning / LSTM? Random Forest provides superior interpretability through feature importance, requires no GPU hardware, trains in seconds, and resists overfitting on tabular residential energy data.
2. How is cost calculated? Calculated using both flat rate (\(\text{kWh} \times \text{Tariff}\)) and progressive utility tiered slabs (Tier 1 Lifeline, Tier 2 Normal, Tier 3 Surcharge).
