# System Requirements Specification

## 1. Hardware Requirements

### Minimum Requirements (Development & Execution):
- **Processor:** Dual-Core Intel Core i3 / AMD Ryzen 3 or higher
- **RAM:** 4 GB RAM (8 GB recommended for simultaneous browser and ML execution)
- **Disk Space:** 500 MB free hard drive space (for dataset, model binary, and database)
- **Display:** 1366x768 resolution or higher

### Recommended Requirements (College Presentation / Viva):
- **Processor:** Quad-Core Intel Core i5 / AMD Ryzen 5 or higher
- **RAM:** 8 GB RAM
- **Disk Space:** 1 GB free SSD storage
- **Display:** Full HD (1920x1080) for high-fidelity dashboard charts

---

## 2. Software Requirements

### Operating System:
- Windows 10/11 (64-bit), macOS 11+, or Ubuntu Linux 20.04+

### Core Runtimes & Interpreters:
- **Python:** Version 3.11 or higher
- **Package Manager:** `pip` or `uv`

### Python Libraries (Backend & Machine Learning):
- **Web Framework:** Flask >= 3.0.0, Werkzeug >= 3.0.0
- **Database & ORM:** SQLAlchemy >= 2.0.0, Flask-SQLAlchemy >= 3.1.1
- **Machine Learning & Math:** Scikit-Learn >= 1.3.0, NumPy >= 1.24.0, Pandas >= 2.0.0, SciPy >= 1.11.0
- **Model Serialization:** Joblib >= 1.3.0
- **Testing:** Pytest >= 7.4.0

### Frontend & Client-Side Technologies:
- **Markup & Styling:** HTML5, CSS3, Bootstrap 5.3.3
- **Scripting:** JavaScript (ES6+)
- **Visualization Library:** Chart.js 4.4.1 (loaded via CDN)
- **Icons:** Bootstrap Icons 1.11.3
- **Web Browser:** Google Chrome, Mozilla Firefox, Microsoft Edge, or Apple Safari
